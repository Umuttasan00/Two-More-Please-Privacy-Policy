# Gizlilik politikası mikro sitesi

`index.html` ve `styles.css` bu klasörde; sayfada önce **English** (`#policy-en`), altında **Türkçe** (`#policy-tr`) yer alır; üstteki dil bağlantılarıyla atlanır. Açmak: `open index.html` veya tam yol.

Doğrudan Türkçe bölüm: `index.html#policy-tr`.

`file://` ile göreli bağlantılar çalışır; CORS gerektiren senaryoda `python3 -m http.server 8765` ile bu klasörden sunabilirsiniz.

İletişim adresi `index.html` içinde güncellenmiş e-postayı kullanır; değiştirmek için aynı dosyada düzenleme yapın.
